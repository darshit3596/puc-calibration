# SHREEJI CALIBRATION & AMC MANAGER

A web-based PUC (Pollution Under Control) calibration certificate and AMC (Annual Maintenance Contract) generator for Petrol and Diesel testing systems.

## ✨ Features
- **Petrol & Diesel Calibration Modes**: Dedicated certificate templates for both vehicle categories.
- **Auto Date Formatting**: Automatically converts selected dates to standard `DD/MM/YYYY` format and aligns them onto the certificate template.
- **Print & PDF Export**: Instant 1-click download via print styling (`@media print`) that produces clean calibration slips.
